# CUDA version

This directory documents the API.cpp CUDA contract for one CUDA toolkit version.

## Required feature pages

- `attention/flash.md`
- `attention/sage.md`
- `attention/xformers.md`
- `attention/flexattention.md`
- `cache/easycache.md`
- `cache/teacache.md`

Each page must be updated from repository code and build validation for this CUDA version. Do not infer support only from newer or older toolkit versions.

## Status fields

Record implementation status, compile status, supported GPU architectures, datatype/head-size restrictions where applicable, native/adapted/fallback behavior, required compiler/toolkit features, fallback behavior, known limitations, and validation evidence.
