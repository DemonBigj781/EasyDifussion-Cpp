# Retained WebGPU validation evidence

These files preserve the downloaded CI artifact metadata, original report/log
bytes and exact verifier scripts for run [37531113555](https://github.com/DemonBigj781/EasyDifussion-Cpp/actions/runs/37531113555).
No application executable or APE loader binary is included.

The [validation summary](../../../COSMOPOLITAN_WEBGPU_VALIDATION.md) distinguishes
this CI artifact from the earlier local build. `local/` contains only that
separately labeled local public CLI result. CI host paths in metadata are
preserved so original file hashes remain valid.

[FILES.json](FILES.json) records SHA-256, byte count, origin and scope for every
retained evidence file. The index and inventory are generated documentation;
the original downloaded metadata/reports/logs are copied without rewriting.

The archive-specific `.gitattributes` disables Git text conversion so these
recorded byte hashes survive checkouts with automatic CRLF conversion.
