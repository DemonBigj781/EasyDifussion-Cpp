# oneAPI xFormers methods

Structural placeholder for feature-first xFormers oneAPI/SYCL method implementations.

Canonical method path: `API.cpp/features/attention/xformers/oneapi/definition/[device]/[method].cpp`.
oneAPI-to-common adapters live under `oneapi/translation/[device]/`.

Backend method files should implement the common xFormers method contract and remain isolated from other backend implementations.
